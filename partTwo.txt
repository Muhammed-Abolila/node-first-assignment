*********** Q2 What is hoisting and what is the Temporal Dead Zone (TDZ)? Explain with examples. (0.5 Grade) ***********
    1-Hoisting:It's a JavaScript behavior where variable and function declarations are processed before code executed.
    2-TDZ: It's the time between entering a scope and initializing a variable declared with let or const.

        console.log(x); undefined

        console.log(x);
